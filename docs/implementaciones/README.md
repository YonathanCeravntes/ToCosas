# 🛠️ Informes de Implementación (IMP) — Millo

Este directorio contiene los **informes de implementación**. Se genera un
`IMP-XXXX-NombreModulo.md` **al finalizar** la implementación de cada módulo
aprobado (mismo número que su `ARQ`/`DEC`).

La plantilla está en [`IMP-0000-Plantilla.md`](IMP-0000-Plantilla.md).

## Secciones mínimas de un informe (IMP)

1. Resumen de implementación
2. Archivos modificados
3. Funcionalidades implementadas
4. Pruebas ejecutadas
5. Incidencias encontradas
6. Limitaciones
7. Resultado final
