# docs/implementaciones — Informes de implementación (IMP)

Aquí viven los documentos `IMP-XXXX-NombreModulo.md`, generados **al finalizar** la
implementación de un módulo autorizado por su `DEC`. Incluyen: resumen, archivos
modificados, funcionalidades, pruebas, incidencias, limitaciones y resultado final.

Ver el proceso completo en [../GOBERNANZA.md](../GOBERNANZA.md).
