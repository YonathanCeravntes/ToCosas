# Archivo histórico — Milla

Regla permanente (Gobernanza v3.0, Parte III §20): **nunca se elimina documentación
oficial.** Todo documento reemplazado o retirado (versiones anteriores de
`docs/GOBERNANZA.md`, documentos `ARQ`/`AUD`/`DEC`/`IMP`/`IDEA` superados por una
revisión posterior, propuestas no adoptadas, etc.) se mueve aquí en vez de borrarse.

La historia del proyecto se conserva íntegra para que cualquier decisión pueda
reconstruirse incluso varios años después.

## Convención de nombres

`archive/<carpeta-origen>/<nombre-original>-v<N>.md` — por ejemplo, si
`docs/GOBERNANZA.md` se reemplaza por una v4.0 en el futuro, la v3.0 se archiva como
`docs/archive/GOBERNANZA-v3.0.md` antes de sobrescribir el archivo vigente.
