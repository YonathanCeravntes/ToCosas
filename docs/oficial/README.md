# 🏛️ Decisiones Oficiales (DEC) — Millo

Este directorio contiene las **decisiones oficiales aprobadas** por la Auditoría
y el CTO. Un documento `DEC-XXXX-NombreModulo.md` es la **autorización formal**
para implementar la propuesta `ARQ-XXXX` correspondiente.

## Regla

> La implementación de un cambio importante **solo puede comenzar** cuando existe
> aquí su `DEC-XXXX` aprobado. La implementación debe seguir **estrictamente** lo
> aprobado en ese DEC.

## Contenido mínimo de un DEC

| Campo | Descripción |
|-------|-------------|
| **ID** | DEC-XXXX (mismo número que su ARQ) |
| **Propuesta origen** | ARQ-XXXX-NombreModulo |
| **Decisión** | Aprobada / Aprobada con cambios / Rechazada |
| **Fecha** | AAAA-MM-DD |
| **Aprobado por** | CTO / Auditoría |
| **Condiciones / ajustes** | Cambios exigidos frente a la propuesta original |
| **Alcance autorizado** | Qué queda autorizado a implementar |
| **Notas de auditoría** | Observaciones, riesgos aceptados |
