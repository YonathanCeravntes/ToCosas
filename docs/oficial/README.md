# docs/oficial — Decisiones oficiales (DEC)

Aquí viven los documentos `DEC-XXXX-NombreModulo.md` (decisiones históricas del CTO tras
la auditoría de un ARQ) y los `DEC-ORG-XXX` (decisiones de organización del Fundador).

**Desde `DEC-ORG-002` (2026-09-27)** no hay CTO: el Fundador decide y el Arquitecto ejecuta.
Una FIN nueva se documenta en un solo archivo `docs/arquitectura/FIN-XXXX-*.md` (ARQ +
Implementado + Decisiones del Fundador); ya no se emiten `DEC-XXXX` por FIN.

Ver el proceso completo en [../GOBERNANZA.md](../GOBERNANZA.md).
